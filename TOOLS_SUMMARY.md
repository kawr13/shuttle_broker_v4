## 🚀 Быстрый старт

### 1. Посмотреть все доступные шаттлы
```bash
shuttle.py list
```

### 2. Отправить команду шаттлу
```bash
# Простая отправка
shuttle.py send shuttle_140 STATUS

# С дополнительными опциями
shuttle.py cmd shuttle_140 HOME --timeout 15 --no-listen
```

### 3. Основные команды для шаттлов
- `STATUS` - запросить статус
- `HOME` - отправить домой  
- `BATTERY` - проверить батарею
- `LOC` - запросить местоположение
- `MRCD` - подтверждение
