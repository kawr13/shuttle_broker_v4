# 🏭 WMS Интеграция - Автоматическое управление шаттлами

## 📋 Обзор

Система автоматически:
1. **Опрашивает WMS** на предмет новых документов
2. **Сохраняет номера документов** и отслеживает их статус
3. **Получает задания** по документам из WMS
4. **Создает команды для шаттлов** автоматически
5. **Обновляет статусы** задач в WMS после выполнения

## 🚀 Быстрый старт

### 1. Настройка конфигурации

Убедитесь, что в `config.yaml` настроена секция WMS:

```yaml
wms:
  api_url: http://10.181.80.28:8080/exec
  username: "1000"
  password: "1000"
  poll_interval: 300  # 5 минут
  webhook_url: http://your-server/webhook
```

## 🔄 Как работает система

### 1. Опрос WMS
- Каждые N секунд (настраивается в `poll_interval`)
- Запрос: `IncomeApi.getObjectsShipment`
- Фильтрация по статусам: `selectionCreated`, `selectionWork`

### 2. Обработка документов
- Сохранение состояния документа
- Запрос задач: `IncomeApi.taskExecutesDoc&p={doc_id}`
- Создание команд для шаттлов

### 3. Создание команд
- Определение типа команды по задаче
- Поиск свободного шаттла
- Отправка команды через ShuttleManager

### 4. Обновление статусов
- Получение ответов от шаттлов
- Обновление статуса в WMS: `IncomeApi.insertUpdate`

## 🎯 Типы команд

### Автоматическое определение команд

| Тип задачи WMS | Команда шаттла | Описание |
|----------------|----------------|----------|
| `*IN*`, `RECEIVE` | `PALLET_IN` | Прием паллеты |
| `*OUT*`, `SHIP` | `PALLET_OUT` | Отгрузка паллеты |
| `MOVE` | `MOVE` | Перемещение |
| По умолчанию | `STATUS` | Запрос статуса |

### Приоритеты задач

| Приоритет WMS | Приоритет команды | Описание |
|---------------|-------------------|----------|
| `urgent` | 1 | Срочные задачи |
| `high` | 3 | Высокий приоритет |
| `normal` | 5 | Обычный приоритет |
| `low` | 7 | Низкий приоритет |

## 🔧 Настройка и конфигурация

### Параметры WMS в config.yaml

```yaml
wms:
  api_url: "http://10.181.80.28:8080/exec"    # URL WMS API
  username: "1000"                             # Пользователь WMS
  password: "1000"                             # Пароль WMS
  poll_interval: 300                           # Интервал опроса (сек)
  webhook_url: "http://gateway/webhook"        # URL для webhook (опционально)
```

### Переменные окружения (альтернатива)

```bash
export WMS_API_URL="http://10.181.80.28:8080/exec"
export WMS_API_USERNAME="1000"
export WMS_API_PASSWORD="1000"
export WMS_POLL_INTERVAL="300"
export WMS_WEBHOOK_URL="http://gateway/webhook"
```

## 🚨 Устранение неполадок

### Частые проблемы

1. **WMS не отвечает**
   ```bash
   # Проверить подключение
   curl -u "1000:1000" "http://10.181.80.28:8080/exec?action=IncomeApi.getObjectsShipment"
   ```

2. **Документы не обрабатываются**
   ```bash
   # Проверить статус
   python wms_monitor.py status
   ```

3. **Команды не создаются**
   ```bash
   # Проверить логи
   tail -f logs/gateway.log | grep WMS
   ```

4. **Файл состояния поврежден**
   ```bash
   # Очистить состояние
   python wms_monitor.py clear
   ```

### Логи и отладка

```bash
# Включить DEBUG логирование в config.yaml
logging:
  level: DEBUG
  file_path: logs/gateway.log

# Просмотр логов WMS
grep "WMS" logs/gateway.log

# Просмотр ошибок
grep "ERROR" logs/gateway.log | grep WMS
```
