# Постоянные TCP-соединения с шаттлами

## Описание

В версии 3.5 добавлена поддержка постоянных TCP-соединений с шаттлами для решения проблемы тайм-аутов и повышения надежности связи.

## Основные возможности

1. **Постоянные соединения**:
   - Соединения с шаттлами поддерживаются активными между командами
   - Автоматическое переподключение при обрыве связи
   - Периодические пинги для предотвращения тайм-аутов

2. **Централизованное управление соединениями**:
   - Единый менеджер соединений для всех компонентов системы
   - Синхронизация доступа к соединениям через блокировки
   - Автоматическое закрытие неактивных соединений

3. **Повышение надежности**:
   - Уменьшение количества переподключений
   - Снижение вероятности тайм-аутов
   - Более быстрая отправка команд

## Настройка

Параметры постоянных соединений настраиваются в файле `config.py`:

```python
# Интервал проверки соединений (секунды)
CONNECTION_HEARTBEAT_INTERVAL = 30
```

## Тестирование

Для тестирования постоянных соединений можно использовать скрипт:

```bash
python test_persistent_connection.py 10.181.80.135
```

## Принцип работы

1. При первой отправке команды шаттлу создается TCP-соединение
2. Соединение сохраняется в менеджере соединений
3. Последующие команды используют существующее соединение
4. Периодически отправляются пустые команды для поддержания соединения
5. Если соединение обрывается, оно автоматически восстанавливается при следующей команде

## Преимущества

- Снижение нагрузки на сеть за счет уменьшения количества установок соединений
- Более быстрая отправка команд (не нужно каждый раз устанавливать соединение)
- Предотвращение тайм-аутов TCP-соединений
- Повышение надежности связи с шаттлами
