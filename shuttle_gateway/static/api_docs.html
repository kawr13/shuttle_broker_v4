API Документация

Шлюз управления шаттлами

Общая информация

API предоставляет доступ к управлению и мониторингу шаттлов через HTTP запросы. Все ответы возвращаются в формате JSON.

Базовый URL: http://localhost:8080

Получение списка шаттлов

GET /api/shuttles

Возвращает список всех доступных шаттлов с их статусами.

Пример ответа:

{
  "shuttles": [
    {
      "id": "10_181_80_135",
      "name": "Shuttle-135",
      "ip": "10.181.80.135",
      "cell": "Cell_1",
      "warehouse": "Warehouse_A",
      "status": "online",
      "battery": "85%",
      "errors": null,
      "last_response": 1625147689.123
    },
    ...
  ]
}

Получение информации о шаттле

GET /api/shuttle/{ip}

Возвращает подробную информацию о конкретном шаттле.

Параметры:

  • ip - IP-адрес шаттла

Пример ответа:

{
  "id": "10_181_80_135",
  "name": "Shuttle-135",
  "ip": "10.181.80.135",
  "cell": "Cell_1",
  "warehouse": "Warehouse_A",
  "status": "online",
  "battery": "85%",
  "errors": null,
  "last_response": 1625147689.123
}

Отправка команды шаттлу

POST /api/command

Отправляет команду указанному шаттлу.

Тело запроса:

{
  "ip": "10.181.80.135",
  "command": "STATUS"
}

Пример ответа:

{
  "status": "success",
  "message": "Command STATUS sent to 10.181.80.135"
}

API для Telegram-бота

Специальные эндпоинты для использования в Telegram-боте.

GET /api/telegram/shuttles

Возвращает список шаттлов в формате, оптимизированном для Telegram-бота.

GET /api/telegram/shuttle/{ip}

Возвращает подробную информацию о шаттле для Telegram-бота. Поддерживает поиск как по IP, так и по имени шаттла.

Поддерживаемые команды

Основные команды:

  • PALLET_IN - Погрузка паллеты
  • PALLET_OUT - Выгрузка паллеты
  • STACK_IN - Уплотнение паллет
  • STACK_OUT - Разуплотнение паллет
  • COUNT - Подсчёт паллет
  • FIFO-nnn - FIFO операция
  • FILO-nnn - FILO операция
  • HOME - Возврат в домашнюю позицию
  • STOP - Остановка

Сервисные команды:

  • STATUS - Запрос статуса
  • BATTERY - Запрос уровня батареи
  • WDH - Запрос часов привода
  • WLH - Запрос состояния подъема
  • MRCD - Подтверждение получения сообщения
