# Веб-интерфейс для управления шаттлами

## Компоненты системы

1. **Веб-сервер (web_server.py)**
   - Обслуживает HTML-интерфейс
   - Предоставляет API для управления шаттлами
   - Отслеживает состояние шаттлов
   - Периодически опрашивает шаттлы для обновления статуса

2. **HTML-интерфейс (index.html)**
   - Отображает список шаттлов с их статусами
   - Позволяет отправлять команды шаттлам
   - Отображает ответы от шаттлов
   - Показывает уровень заряда батареи и ошибки

3. **Телеграм-бот (telegram_bot.py)**
   - Предоставляет доступ к информации о шаттлах через Telegram
   - Позволяет получать статус системы
   - Отображает подробную информацию о конкретном шаттле

## API эндпоинты

- `GET /api/shuttles` - Получение списка всех шаттлов
- `GET /api/shuttle/{ip}` - Получение информации о конкретном шаттле
- `POST /api/command` - Отправка команды шаттлу
- `GET /api/telegram/shuttles` - API для телеграм-бота (список шаттлов)
- `GET /api/telegram/shuttle/{ip}` - API для телеграм-бота (информация о шаттле)

## Поддерживаемые команды

### Основные команды
- `PALLET_IN` - Погрузка паллеты
- `PALLET_OUT` - Выгрузка паллеты
- `STACK_IN` - Уплотнение паллет
- `STACK_OUT` - Разуплотнение паллет
- `COUNT` - Подсчёт паллет
- `FIFO-nnn` - FIFO операция
- `FILO-nnn` - FILO операция
- `HOME` - Возврат в домашнюю позицию
- `STOP` - Остановка

### Сервисные команды
- `STATUS` - Запрос статуса
- `BATTERY` - Запрос уровня батареи
- `WDH` - Запрос часов привода
- `WLH` - Запрос состояния подъема
- `MRCD` - Подтверждение получения сообщения

## Запуск системы

```bash
# Запуск с телеграм-ботом
TELEGRAM_TOKEN=your_token python main.py

# Запуск без телеграм-бота
python main.py
```
