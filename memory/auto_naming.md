# Автоматическое именование шаттлов

## Правила именования

Система автоматически именует шаттлы по следующим правилам:

1. **IP-адреса 10.181.80.131 - 10.181.80.139**
   - Шаттл_1 - Шаттл_9
   - Формула: `Шаттл_{последний октет - 130}`

2. **IP-адреса 10.181.80.140 - 10.181.80.149**
   - Шаттл_10 - Шаттл_19
   - Формула: `Шаттл_{последний октет - 130}`

3. **Другие IP-адреса**
   - Shuttle-{последний октет}
   - Например: Shuttle-150, Shuttle-200

## Приоритет именования

1. Пользовательское имя из файла конфигурации (если задано)
2. Автоматически сгенерированное имя по правилам выше

## Реализация

Функция `get_shuttle_name` в `web_server.py` реализует эту логику:

```python
def get_shuttle_name(ip, custom_name=None):
    """
    Генерирует имя шаттла на основе IP-адреса или возвращает пользовательское имя
    """
    if custom_name:
        return custom_name
        
    try:
        last_octet = int(ip.split('.')[-1])
        if 131 <= last_octet <= 139:
            return f"Шаттл_{last_octet - 130}"
        elif 140 <= last_octet <= 149:
            return f"Шаттл_{last_octet - 130}"
        else:
            return f"Shuttle-{last_octet}"
    except (ValueError, IndexError):
        return f"Shuttle-{ip}"
```
