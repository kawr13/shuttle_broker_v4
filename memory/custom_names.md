# Поддержка пользовательских имен для шаттлов

## Обновления в системе

1. **Обновлена структура shuttles.json**
   ```json
   {
     "shuttles": [
       {
         "ip": "10.181.80.135",
         "name": "Шаттл-1",  // Пользовательское имя (опционально)
         "cell": "Cell_1",
         "warehouse": "Warehouse_A"
       },
       ...
     ]
   }
   ```

2. **Обновлен метод add_shuttle в ShuttleClient**
   - Добавлен параметр `name` для указания пользовательского имени
   - Имя сохраняется в конфигурации, если оно указано

3. **Обновлен веб-сервер для использования пользовательских имен**
   - В методе `get_shuttles` используется имя из конфигурации, если оно задано
   - В методе `get_shuttle_info` используется имя из конфигурации
   - В методах для телеграм-бота также используются пользовательские имена

4. **Обновлен поиск шаттлов по имени**
   - Теперь поиск учитывает пользовательские имена

## Как использовать

1. Отредактируйте файл `shuttles.json` и добавьте поле `"name"` для нужных шаттлов
2. Перезапустите систему для применения изменений
3. Имена будут отображаться в веб-интерфейсе и телеграм-боте

## Пример конфигурации

```json
{
  "shuttles": [
    {
      "ip": "10.181.80.135",
      "name": "Шаттл-Главный",
      "cell": "Cell_1",
      "warehouse": "Warehouse_A"
    },
    {
      "ip": "10.181.80.136",
      "name": "Шаттл-Запасной",
      "cell": "Cell_2",
      "warehouse": "Warehouse_A"
    }
  ]
}
```
